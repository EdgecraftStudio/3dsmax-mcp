# Contributing

Contributions are welcome. Adding support for more 3rd party renderers or plugins are also welcome. However going out of scope I will most likely reject it (such as an user interface). 3dsmax-mcp aims to be renderer/plugin agnostic as possible however a lot of tools have dedicated support for v-ray, corona and fstorm.

Even without these tools an agent can likely figure out via MaxScript feedback loop but that is inefficent and it's a dice roll every time. That's why they exist.

Please test the tools yourself using real world scenarios instead of just trusting agents "smoke tests" passing. Non English PRs are instantly rejected.
